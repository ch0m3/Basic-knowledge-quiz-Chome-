# Herb & Spice Trivia CLI Game

A small Node.js command-line trivia game about herbs, spices, and plants. It asks multiple-choice questions, gives the player 10 seconds per question, and shows the final score.

## Features
- Interactive CLI quiz with multiple-choice answers
- 10-second countdown per question
- Immediate feedback (correct/incorrect) and final score

## Running the game

You can run the game directly with Node:

```bash
node trivia-cli.js
```

Alternatively make the script executable and run it (the file has a shebang):

```bash
chmod +x trivia-cli.js
./trivia-cli.js
```

## How to play
- Each question displays four numbered answers.
- You have 5 seconds to respond to each question.
- Type the number `1`–`4` corresponding to your choice and press Enter.
- If time runs out, the correct answer is shown and the quiz moves on.
- Your final score is shown at the end.
